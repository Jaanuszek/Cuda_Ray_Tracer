Detailed Description

Definicja klasy metal.

Klasa metal dziedziczy po klasie material. Przechowuje informacje o albedo (kolorze) materialu oraz jego "szorstkoœci" (fuzz).

Przeciazona funkcja scatter, ktora oblicza oraz odbija promien.

W przypadku gdy fuzz jest rowny 0, to promien jest idealnie odbijany (powstaje efekt lustrzany). Jezeli jednak fuzz jest wiekszy niz zero, to promien jest odbijany w losowym kierunku, przez co powstaje efekt rozproszenia swiatla a w konsekwencji brak idealnego zjawiska lustra.
